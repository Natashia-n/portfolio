# Sitho Portfolio

A modern, responsive developer portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Before publishing

Replace the placeholder:
- GitHub URL
- LinkedIn URL
- Email address
- Resume link/download
- Project case-study links

The portfolio content is intentionally based on Sitho's known academic, project, technical and leadership background.
